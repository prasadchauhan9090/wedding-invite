PUT YOUR WEDDING SONG HERE

1. Copy your mp3 into this folder and name it:  song.mp3
   (or change the file name in js/config.js -> song.file)
2. Keep the file small (under 5-6 MB) so the page loads fast on phones.
   Tip: trim to 2-3 minutes; the site plays it on loop.
3. Use a song you have the right to use (your own, royalty-free, or licensed).

If song.mp3 is missing, the music button is simply hidden - the site still works.
